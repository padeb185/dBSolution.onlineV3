{% trans "Congés payés" %}

  • {% trans "20 jours par an pour un temps plein (5 jours / semaine) ayant travaillé toute l'année précédente (exercice de vacances)." %}
  • {% trans "Temps partiel ou année incomplète : au prorata (régime de travail, jours prestés ou assimilés)." %}
  • {% trans "Les jours doivent être pris avant le 31 décembre ; ils ne sont pas reportables ni payables (sauf à la sortie)." %}
  • {% trans "Salaire journalier d'un employé : salaire mensuel × 3 / 65." %}

{% trans "Pécule de vacances" %}

  • {% trans "Employé" %} : {% trans "simple pécule = salaire maintenu pendant les jours pris ; double pécule = 92 % du brut mensuel, payé en général en mai / juin." %}
  • {% trans "ONSS sur le double pécule : 13,07 % calculés sur 85 % (la part de 7 % n'est pas soumise) ; précompte au taux des allocations exceptionnelles." %}
  • {% trans "Ouvrier" %} : {% trans "payé par la caisse de vacances : 15,38 % du brut à 108 % de l'année précédente (8 % simple + 7,38 % double). L'employeur cotise 15,84 % du brut à 108 %." %}

{% trans "Prime de fin d'année (13e mois)" %}

  • CP 200 : {% trans "un salaire mensuel brut, au prorata des mois prestés ou assimilés de l'année civile, payé en décembre." %}
  • CP 112 : {% trans "taux horaire au 1er décembre × 38 h × 52 / 12, période du 1er décembre au 30 novembre, payée au plus tard le 20 décembre (minimum 3 mois d'ancienneté)." %}
  • {% trans "ONSS 13,07 % (sur 108 % pour un ouvrier), sans bonus à l'emploi ; précompte au taux des allocations exceptionnelles." %}
